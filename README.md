## Fraud Detection Using Machine Learning

**Objective:** Developed a machine learning system for detecting fraudulent financial transactions with imbalanced data.

- **Developed** a **Logistic Regression** classifier with **class-weighted learning**, achieving **~93% fraud recall** on highly imbalanced transaction data.
- **Engineered** a leakage-resistant **Scikit-learn Pipeline** for preprocessing categorical and numerical features.
- **Deployed** the trained model using **Streamlit** for real-time fraud prediction with transaction-level probability scoring.
